奈儿 网页桌宠 · 复制即用

一只住在网页里的 Q 版小女仆：自己走动、随机卖萌，也能陪你聊天。她只在你打开这个页面时出现，不需要安装任何东西。

怎么用她

  • 点她一下：她会回应你（开心/害羞/傲娇…）
  • 按住拖动：把她挪到任意位置；甩出去她会飞一段再落回地面
  • 右键点她：弹出菜单，可以点播 100+ 个动画，也可以「对话」「碎碎念」「查看余额」
  • 左下角齿轮：填你自己的 API Key、选模型、调大小、开关朗读

第一次使用：填 API Key

  • 默认走 DeepSeek 官方：到 platform.deepseek.com 创建 API Key，粘进设置面板即可
  • 也可以用任何 OpenAI 兼容的接口：把「接口地址」和「模型」换成对方的即可（例如公司中转）
  • Key 只存在你自己的浏览器本地（localStorage），不会上传到任何第三方服务器；她说话是直接调你填的那个接口

说明

  • 聊天时会带上最近几轮记忆（存在浏览器本地），语气是「调皮可爱」那一套
  • 动画素材来自 DSH 桌宠项目 dsh-pet（MIT + 素材开源、禁止商用）
  • 把整个文件夹拷给别人 / 放到任意静态服务器上都能直接用；纯前端，没有服务端
