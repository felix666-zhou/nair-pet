奈儿 · 网页桌宠（复制即用）
========================================

【最快用法：直接双击】
双击 index.html → 浏览器里就出现奈儿（她自己走动、随机卖萌）。
第一次用：点左下角 ⚙ → 填上你自己的 API Key → 保存 → 右键点她 →「对话」就能聊了。

【如果双击打不开 / 想要一个网址】
双击「启动奈儿网站.cmd」→ 它会在本机起一个极小的静态服务并自动打开浏览器
（地址 http://127.0.0.1:8080/ ，只监听本机，不对外）。
这条路径也适合：把整个文件夹放到公司内网服务器 / 任意静态托管上，同事打开网址就能用。

【每人自己填 Key】
点左下角 ⚙ 打开设置：
  接口地址  默认 https://api.deepseek.com （任何 OpenAI 兼容接口都行）
  模型      默认 deepseek-chat （用别的服务商就填它的模型名）
  API Key   填你自己的（DeepSeek 官方到 platform.deepseek.com 创建）
  她的大小  280 / 340 / 420 / 462 / 560 px
  人设      她说话的语气（默认就是"调皮可爱"那套）
  朗读      勾上后她说话会用浏览器语音念出来
「测试连接」会真发一条最小请求，用来确认 Key 和接口能通。

Key 只存在**使用者自己的浏览器**里（localStorage），不会上传到任何服务器；
所有请求都是从浏览器直接发往"接口地址"里填的那个服务（没有中间服务器）。

【怎么玩她】
  单击          她会回应你（开心/害羞/傲娇/挠痒/挥手）
  按住拖动      挪到任意位置；甩出去会飞一段、落地弹一下
  右键          菜单：对话 / 碎碎念 / 查看余额 / 回到初始位置 / 设置 + 100 多个动画点播
                  （待机、转向、拖拽、点击回应、移动、小动作、玩耍、吃什么、时节、文字、余额档位、碎碎念、工作状态）
  左下角齿轮    设置
  页面按钮      「让她说句话」「让她停下 / 继续走动」

【对话记忆】
最近几轮对话存在浏览器本地（localStorage），设置面板里有「清空对话记忆」。

【文件说明】
  index.html           页面（含样式）
  pet.js               桌宠主程序（行为循环 / 拖拽甩飞 / 菜单 / 对话 / 设置）
  shared-core.js       与桌面版共用的组件（右键菜单、聊天气泡、物理参数）——来自 dsh-pet
  config.js / config.json  她的配置：动画池、权重、人设、默认大小（改完保存即可，刷新生效）
  assets/webm/         106 段透明动画（VP9-alpha，Chrome / Edge / Firefox 均可）
  assets/fonts/        气泡字体（上首软糖体）
  serve.ps1            微型静态服务器（仅用系统自带 PowerShell，无依赖）
  启动奈儿网站.cmd     双击启动它

【常见问题】
  · 她不动 / 不显示？     换成 Chrome 或 Edge 打开（Firefox 也支持）；IE 不支持
  · 聊天报 401？          检查 Key 是否正确、有没有余额；换接口时确认"接口地址+模型"是配套的
  · 聊天报网络错误？      多数是"接口地址"填错或该服务不允许浏览器直连（换用支持跨域的接口）
  · 刷新后 Key 还在吗？   在（存在浏览器本地）；换浏览器/清缓存就要重新填
  · 会不会花我的钱？      只在你自己点「对话 / 碎碎念」时才会调用你填的接口；她走动、播放动画完全本地，不花钱
